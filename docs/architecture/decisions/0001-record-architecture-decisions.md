# 1. Record architecture decisions

Date: 2026-10-17

## Status

Accepted

## Context

Decisions made while building closeout should be findable by whoever changes the
code next, including when the product grows beyond one personal store.

## Decision

Record architecturally significant decisions as numbered ADRs in
`docs/architecture/decisions/`, following the format used by the author's other
projects (Fortuna, Loci).

## Consequences

A decision that changes one of these records gets a new ADR that supersedes it.
